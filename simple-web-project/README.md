# Simple Web Project

這是一個簡單的網頁專案，旨在展示基本的HTML和CSS用法。

## 專案結構

```
simple-web-project
├── src
│   ├── index.html       # 網頁的主檔案，包含HTML結構和內容
│   ├── css
│   │   └── styles.css   # 樣式表檔案，定義網頁的樣式
└── README.md            # 專案文檔，說明專案的目的和使用方法
```

## 使用方法

1. 克隆或下載此專案。
2. 打開 `src/index.html` 檔案以查看網頁。
3. 可以編輯 `src/css/styles.css` 來修改網頁的樣式。

## 目的

此專案旨在幫助學習者理解基本的網頁結構和樣式設計，並提供一個簡單的範例作為起點。
